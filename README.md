# LUPA Móvil — versiones

Acá solo se publican los APK de LUPA Móvil (en **Releases**). El código está en un repo privado.
La app consulta el último release al abrir y ofrece instalarlo.

Instalar a mano: bajar `lupa-movil.apk` del último release, abrirlo en el celular y permitir «instalar apps desconocidas».
